# Pablo Oca Galeano — Personal Website

[![GitHub Pages](https://img.shields.io/badge/live-pablooca.github.io-0b0d10?style=flat-square)](https://pablooca.github.io)

Personal website and technical portfolio of **Pablo Oca Galeano** — Software Engineer · AI & High-Performance Computing (HPC) Researcher · Data Engineer, based in Seville, Spain.

🔗 **Live:** https://pablooca.github.io

## Highlights

- Bilingual interface (**EN** default / **ES**) with instant switching and `localStorage` persistence.
- Dark (default) and light themes, respecting the system preference.
- 100% static: HTML5 + CSS3 + vanilla JavaScript. No build step, served directly from `main`.
- SEO & Open Graph metadata for clean previews on LinkedIn.
- Fully responsive, accessible (semantic landmarks, skip link, reduced-motion support).

## Structure

```
.
├── index.html          # Single-page layout, SEO / Open Graph metadata
├── css/styles.css      # Design system (tokens, themes, layout, components)
├── js/i18n.js          # EN / ES dictionary + language switcher
├── js/main.js          # Theme toggle, navigation, scroll reveal
├── assets/img/         # Web-optimised photos (generated by setup_assets.sh)
└── setup_assets.sh     # macOS script: copy + convert HEIC → JPEG with `sips`
```

## Local development

```bash
./setup_assets.sh            # (macOS) regenerate ./assets/img from ~/Desktop/Fotos
python3 -m http.server 8000  # then open http://localhost:8000
```
